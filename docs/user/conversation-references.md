# Conversation references

Right-click a conversation in either sidebar and choose **Copy conversation**. T3 Code takes a point-in-time copy of its visible user and assistant messages. Paste it into another conversation's composer to add a removable **Conversation** reference chip.

When you send, the reference is added ahead of your request as a clearly marked chronological transcript. The source thread can change or disappear after copying without changing the pasted reference.

Up to eight of the newest source images (no larger than 10 MiB each) are copied into the target composer as normal attachments. If an image cannot be fetched or is too large, the transcript keeps an explicit omission marker. Existing composer attachment limits still apply when pasting.

Some browser and desktop clipboard implementations reject custom clipboard types. In that case, T3 Code copies a readable transcript instead; pasting it inserts ordinary text rather than a reference chip or images.
